# Royale game of ur

A fun, animated web app for playing the Royal Game of Ur in the browser, starting with local human-vs-computer and same-device human-vs-human play. Phase 1 focuses on a polished local playable game with legal move enforcement, simple rule-based AI, win state, and accessible animations without paid gameplay API or LLM calls.

## Quick start

```sh
pnpm install
pnpm dev:up
```

See `docs/local-development.md` for details and `docs/deploy.md` for deployment suggestions.

## How this project is built

The plan lives in GitHub issues (tracking issue #9). `AGENTS.md` holds the rules every contributor — human or agent — follows; `.claude/commands/` has the same workflow for manual use with Claude Code.
