# 0001. Use Next.js with TypeScript for the web app

- Status: Accepted
- Date: 2026-11-19

## Context

The project is a browser game in a new empty repository and the owner prefers TypeScript, Node.js, and Next.js.

## Decision

Use the Next.js App Router template with TypeScript as the only Phase 1 app stack.

## Consequences

The app can be built and tested as a modern web app without a separate backend. The team avoids unnecessary database or API complexity until features require it.
